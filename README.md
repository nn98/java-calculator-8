- ### ❗이슈 1 : 빈 문자열과 확장
- 빈 문자열은 0으로 처리한다.
- 숫자만 있는 문자열은 그 숫자로 처리한다.
- 그렇다면 `구분자`만 있는 문자열은?
  - 계산기에 +만 입력한다고 오류가 나진 않는다
  - `빈 문자열` + `구분자`로 생각? ✅
    - 한다면 결과는 0
  - 오류로 생각?
    - 한다면 예외 처리
- 마찬가지로 커스텀 `구분자`만 있는 문자열은?
  - 마잔가지로 `빈 문자열` + `구분자`로 생각? ✅
    - 한다면 결과는 0
  - 오류로 생각?
    - 한다면 예외 처리
- ### 구분자만 있는 문자열을 0으로 처리한 이유
  - `계산기`를 실행하고, `🪟 + 계산기 + 엔터` 
  - `+`를 누르고, 
  - `=`을 누른다.
  - 결과는?
  - `0`

- ### ❗이슈 1-1 : 구분자의 연속
- `계산기`를 실행한 김에 다양한 예외처리를 시도해보자
- 연산자(구분자)를 여러번 누른다고 오류가 나진 않는다
- 실제 수식을 생각해 봐도 
  - `➖➖` 🟰 `➕` 지만 
  - `➕➕` 🟰 `➕` 이다.
- ∴ 이슈 1의 해결과 동일하게 구분자가 연속해서 입력된 경우도 0으로 처리
