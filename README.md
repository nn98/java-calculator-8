# 문자열 덧셈 계산기

# 기능 요구 사항

입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

- 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달받는 경우 구분자를 기준으로 분리한 각 숫자의 합을 반환한다.  
  - 예: `"1,2:3" => 6`, `"1,2,3" => 6`, `"1:2:3" => 6`
- 앞의 기본 구분자(쉼표, 콜론) 외에 커스텀 구분자를 지정할 수 있다.  
  커스텀 구분자는 문자열 앞부분의 `"//"`와 `"\n"` 사이에 위치하는 값을 커스텀 구분자로 사용한다.  
  - 예를 들어 `"//;\n1;2;3"`과 같이 값을 입력할 경우 커스텀 구분자는 세미콜론(;)이며, 결과 값은 6이 반환되어야 한다.
- 사용자 입력값이 잘못된 경우 적절한 `IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료되어야 한다.

---

## 입출력 요구 사항

### 입력
- 구분자와 양수로 구성된 문자열

### 출력
- 덧셈 결과

```
결과 : 6
```

### 실행 결과 예시

```
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```

## 프로그래밍 요구 사항

- JDK 21 버전에서 실행 가능해야 한다.
- 프로그램 실행의 시작점은 `Application`의 `main()`이다.
- `build.gradle` 파일은 변경할 수 없으며, 제공된 라이브러리 이외의 외부 라이브러리는 사용하지 않는다.
- 프로그램 종료 시 `System.exit()`를 호출하지 않는다.
- 프로그래밍 요구 사항에서 달리 언급하지 않는 한 파일, 패키지 등의 이름을 바꾸거나 이동하지 않는다.
- 자바 코드 컨벤션을 지키면서 프로그래밍한다.  
  - 기본적으로 [Java Style Guide]를 원칙으로 한다.

- ### ❗이슈 1 : 빈 문자열과 확장
- 빈 문자열은 0으로 처리한다.
- 숫자만 있는 문자열은 그 숫자로 처리한다.
- 그렇다면 `구분자`만 있는 문자열은?
  - 계산기에 +만 입력한다고 오류가 나진 않는다
  - `빈 문자열` + `구분자`로 생각? ✅
    - 한다면 결과는 0
  - 오류로 생각?
    - 한다면 예외 처리
- 마찬가지로 커스텀 `구분자`만 있는 문자열은?
  - 마잔가지로 `빈 문자열` + `구분자`로 생각? ✅
    - 한다면 결과는 0
  - 오류로 생각?
    - 한다면 예외 처리
- ### 구분자만 있는 문자열을 0으로 처리한 이유
  - `계산기`를 실행하고, `🪟 + 계산기 + 엔터` 
  - `+`를 누르고, 
  - `=`을 누른다.
  - 결과는?
  - `0`
