### ❗이슈 1 : 빈 문자열과 확장

- 숫자만 있는 문자열은 그 숫자로 처리한다.
- 그렇다면 `구분자`만 있는 문자열은?
  - 계산기에 +만 입력한다고 오류가 나진 않는다
  - `빈 문자열` + `구분자`로 생각? ✅
    - 한다면 결과는 0
  - 오류로 생각?
    - 한다면 예외 처리
- 마찬가지로 커스텀 `구분자`만 있는 문자열은?
  - 마잔가지로 `빈 문자열` + `구분자`로 생각? ✅
    - 한다면 결과는 0
  - 오류로 생각?
    - 한다면 예외 처리
